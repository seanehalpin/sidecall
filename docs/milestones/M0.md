## Spec changes (call-outs)

These change the design, not just add detail. The full list is at the end of `docs/spikes.md`.

1. **React 19 gets element precision** (§5.4, §13). The open question about a dev plugin is closed.
2. **The picker needs a React DevTools shim** (§5.2). Without it, DevTools breaks whenever our script loads first.
3. **Permissions are enforced in two layers** (§6.5, §7): a PreToolUse hook running the classifier, plus `can_use_tool` for approvals. acceptEdits alone lets some commands through.
4. **The talker is locked down with `tools=[Read, Grep, Glob]`** (§6.3). The allow/deny lists alone weren't enough.
5. **STT runs offline per VAD segment, not streaming** (§6.8). parakeet-mlx streaming timestamps break on long input.
6. **Turn continuation** (§6.9, new): merge speech resumed shortly after Smart Turn ends a turn.
7. **The keepalive is JSON `ping`/`pong`, with an alarm wake** (§5.6, §9). Protocol pings don't keep the service worker alive.
8. **The manifest pins a `key`** (§6.1), so the Origin check has a stable extension ID.

## Manual verification

These need your Chrome, your mic and your speakers. The steps are in order of importance; detailed sub-steps are in each spike's FINDINGS.md.

### A. Echo cancellation (the only fully open risk)

Setup: `cd spikes/extension && pnpm install && pnpm build`, then load `spikes/extension/.output/chrome-mv3` unpacked in `chrome://extensions` (Developer mode on). Use built-in speakers, **no headphones**, with volume at 50–70 %.

1. **Grant the mic.** Click the toolbar icon to open the side panel. Click **Open options (grant mic)**, then **Grant microphone**, and allow it. **Expected:** the options tab shows "Granted. Device: …", and the panel header shows `granted`.
2. **Run the test.** In the panel, click **Run echo test** and stay silent for about 2 min. **Expected:** you hear the clip 12 times, and a results table appears.
3. **Read the table.** **Expected:** every `AEC off` row shows leak ≥ 10 dB; if not, raise the volume and rerun. The key row is `webrtc · AEC true`, which should read **cancelled**. If it doesn't, we fall back to requiring headphones.
4. **Report back.** Send the table or JSON, your `chrome://version`, and the value of `chrome://flags/#chrome-wide-echo-cancellation`.

### B. Mic in the extension

5. **Before granting** (use a fresh profile, or reset the mic permission for the extension): click **Record 5 s**. **Expected:** no prompt appears, and the result shows `NotAllowedError`.
6. **Can the panel prompt?** Click **Try getUserMedia in side panel**. **Record:** does a prompt appear, or does it fail, and with which error? This decides whether the options-page detour is always needed.
7. **Record.** After granting (step 1), click **Record 5 s** and speak. **Expected:** your voice plays back after 5 s, and `rmsDb` is roughly −45 to −15.
8. **Survives the panel closing.** Close the side panel and reopen it, then record again. **Expected:** it works with no new prompt, and `offscreen.html` stays listed under "Inspect views".

### C. Voice loop

Setup: `cd spikes/voice && uv sync && uv run python server.py`, wait for `models ready`, then open http://localhost:7860 in Chrome.

9. **Connect and speak.** Click **Connect**, allow the mic, and say "Make the card header red and drop the shadow." **Expected:** a correct transcript, you hear "You said: …", and the latency line is under 1000 ms.
10. **Mid-sentence pause.** Say "Make this…", pause about 1 s, then "…bigger." **Record:** did it split into two turns, and at what pause length? This tunes the turn-continuation thresholds.
11. **Barge-in.** Tick **slow / long replies**, ask anything, then talk over the reply. **Expected:** the bot audio stops within about 0.5 s, and your new utterance is answered.
12. **Echo on the voice path.** On speakers with long replies on, stay silent. **Expected:** the bot doesn't interrupt itself or transcribe its own voice.

### D. Picker with React DevTools

Setup: `cd spikes/picker && pnpm install && pnpm build`, then load `spikes/picker/ext` unpacked, run `cd fixtures/react19-app && pnpm dev`, and open http://localhost:5175. Keep your React Developer Tools extension enabled.

13. **Pick.** Alt+click "Project 3". **Expected:** the console logs `[sidecall] pick` with `…/Card.tsx` line 10, precision `element` and repeat `2/12`, and nothing happens on the page.
14. **DevTools hook.** Run `__REACT_DEVTOOLS_GLOBAL_HOOK__._isBippyHook, __REACT_DEVTOOLS_GLOBAL_HOOK__.rendererInterfaces.size`. **Expected:** `undefined 1`.
15. **DevTools panel.** Open the ⚛ Components tab. **Expected:** the tree shows `App → Sidebar, CardList → Card×12, Form`, and props are visible.

### E. Optional

16. **Service worker WebSocket in real Chrome.** Follow step 13 in `spikes/extension/FINDINGS.md` (30 min). **Expected:** 1 connect, 0 disconnects.

## Known issues

- **Echo cancellation is unverified** until A is run.
- **Smart Turn ends turns early** at mid-sentence pauses of 240–420 ms on synthetic speech. The mitigation is specced (§6.9 turn continuation), but the thresholds need C-10.
- **One unexplained 30-minute run stalled** at 25.7 min, server-side, with no disconnect logged. The re-run with monitoring was clean. Keep an eye on it in M1.
- **The first voice turn of a session is slower** (about 0.8–1.15 s) while MLX compiles kernels. Fix it by warming up with several audio lengths in M3.
- **An in-flight Kokoro sentence can't be aborted mid-segment** (up to about 0.3 s of executor time after a barge-in). Audio output stops immediately regardless.
- **The Agent SDK uses its own bundled CLI** (2.1.292), not your installed `claude` (2.1.293), unless `cli_path` is set.
- **Ports 5173 and 5174 are in use on this machine** by other dev servers. Use `PORT=` for the fixtures.
- **bippy's `hasOwnProperty` bug** should be reported upstream; we carry a shim until then.
- **Subagents couldn't write report files**, so the coordinator wrote each `FINDINGS.md` from the subagent's report and verified the picker, extension unit tests and voice harness by re-running them.
